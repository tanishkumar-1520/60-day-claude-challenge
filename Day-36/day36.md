# Day 36 – Cognitive Pattern Explorer

## Project Overview

For Day 36 of the 60 Days of Claude AI Challenge, I created **Cognitive Pattern Explorer**, an offline psychology-inspired self-reflection web application.

The experience helps users explore their thinking tendencies through interactive everyday scenarios rather than treating the experience like a traditional test.

## Key Features

* Calm Mode and Stress Mode
* Chapter 1: Discover Your Thinking Style
* Interactive everyday decision-making scenarios
* Chapter 2: Choose Your Priorities
* Native drag-and-drop priority activities
* Touch-friendly fallback for drag-and-drop
* Chapter 3: Map Your Thinking
* Interactive thinking timeline
* Personalized Reflection Journal
* Percentage-based thinking profile
* Comparison of thinking tendencies across chapters
* Replay experience in the opposite mode
* Responsive design for desktop, tablet, and mobile
* Keyboard accessibility
* Reduced-motion support
* Ambient background animations
* Smooth transitions and progress tracking
* Completely offline
* Single HTML file using only HTML, CSS, and vanilla JavaScript

## Thinking Tendencies

The application explores five reflective tendencies:

1. Analytical Thinker
2. Emotional Intuitive
3. Overthinking Loop Style
4. Action-First Decision Maker
5. Balanced Reflective Thinker

These are presented as reflective tendencies rather than diagnoses or fixed personality labels.

## What I Learned

* How to design an interactive experience around reflection instead of traditional quizzes.
* How to create reusable JavaScript data structures for scenarios and scoring.
* How to implement native HTML drag-and-drop interactions.
* How to provide a touch-friendly fallback for drag-and-drop interactions.
* How to manage multi-chapter application state with vanilla JavaScript.
* How to calculate and visualize percentage-based results dynamically.
* How to create personalized feedback from user interaction data.
* How to design responsive layouts without using frameworks.
* How to add keyboard accessibility to interactive elements.
* How to respect `prefers-reduced-motion` for accessibility.
* How to build a complete offline application inside a single HTML file.

## Technical Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Native Drag and Drop API
* No frameworks
* No backend
* No external APIs
* No external assets

## Challenge Workflow

1. Read the provided resources.
2. Reviewed the solution/reference material.
3. Opened Claude.
4. Set Claude effort level to Low.
5. Started a new conversation.
6. Used the Cognitive Pattern Explorer prompt.
7. Generated the complete HTML application.
8. Saved the generated HTML file.
9. Opened the application in the browser.
10. Explored Calm Mode and Stress Mode.
11. Completed the Chapter 1 scenarios.
12. Completed the Chapter 2 priority activity.
13. Arranged the Chapter 3 thinking sequence.
14. Reviewed the Reflection Journal.
15. Compared the thinking tendencies.
16. Replayed the experience using the opposite mode.
17. Captured screenshots of the Reflection Journal and thinking profile.
18. Added the project files to the Day36 GitHub folder.
19. Committed and pushed the changes.

## Note

This application is designed for **educational self-reflection only**. Its results are not psychological measurements and should not be interpreted as a mental-health diagnosis or clinical assessment.
