# Day 5 – Context Engineering

## What is Context Engineering?

Context Engineering means providing AI with relevant background information before asking a question.

The more useful context you provide, the more personalized, accurate, and actionable the AI's response becomes.

---

# Prompt A (Without Context)

## Prompt

Create a 30-day learning roadmap.

Include:
- Weekly milestones
- Daily tasks
- Resources
- Projects
- Final outcome

Make it practical and beginner-friendly.

---

## Output Summary

The roadmap was generic and suitable for any beginner.

It included:
- Weekly milestones
- Daily practice
- Basic resources
- Beginner projects

However, it did not consider my background, goals, or available time.

---

# Prompt B (With Context)

## Prompt

Create a 30-day learning roadmap.

Context:

- Current Situation: Student (4th Year B.Tech CSE)
- Current Skills: HTML, CSS, JavaScript, Node.js, Express.js, MongoDB, Git & GitHub
- Goal: Become a Full Stack Developer
- Available Time: 4 Hours per Day
- Experience Level: Intermediate
- Preferred Learning Style: Projects + Videos

Include:
- Weekly milestones
- Daily tasks
- Resources
- Projects
- Final outcome

Make it practical and beginner-friendly.

---

## Output Summary

The roadmap became much more personalized.

It focused on:
- React.js
- Advanced JavaScript
- Backend APIs
- Full Stack Projects
- Portfolio Improvement
- Job Preparation

The learning plan matched my current skills and career goal.

---

# Comparison

## 1. Which roadmap feels more personalized?

Prompt B (With Context)

---

## 2. Which roadmap would you actually follow?

Prompt B

Because it is designed according to my current skills, learning style, and career goal.

---

## 3. What role did context play?

Context helped AI understand my background, experience level, available time, and objective.

As a result, the roadmap became more relevant, practical, and personalized.

---

# Key Learnings

- Better context leads to better AI responses.
- Personalized prompts create more useful outputs.
- AI performs best when given clear background information.
- Context Engineering is one of the most powerful Prompt Engineering techniques.
