# Day 9 - NutriScope

## Project

NutriScope is a single-file nutrition tracking and analysis application.

## MVP Version

The MVP provides:

- User profile inputs
- Food logging
- 20 common foods
- Nutrition tracking
- Macro and micronutrient calculations
- Energy progress
- Nutrient dashboard
- Basic recommendations

## Enhanced Version

The enhanced version adds:

- CSV upload
- 40 additional foods
- More micronutrients
- Two-day meal planner
- Risk analysis
- Educational disclaimer
- Nutrition sources
- Advanced recommendations
- Improved charts

## MVP vs Enhanced

| Feature | MVP | Enhanced |
|---|---|---|
| Profile | ✅ | ✅ |
| Food Logging | ✅ | ✅ |
| Food Database | 20 foods | 60 foods |
| Macro Tracking | ✅ | ✅ |
| Micronutrients | Basic | Advanced |
| CSV Upload | ❌ | ✅ |
| Meal Planner | ❌ | ✅ |
| Risk Analysis | ❌ | ✅ |
| Recommendations | Basic | Advanced |
| Charts | Basic | Improved |

## Key Learnings

1. An MVP focuses on the core functionality of a product.
2. Features can be added incrementally after the basic version works.
3. Enhancing an existing application is easier when the initial structure is modular.
4. Better data and visualizations can make a dashboard more useful.
5. User-focused features such as meal planning and recommendations improve the overall experience.

## Biggest Difference

The MVP focuses on basic nutrition tracking, while the enhanced version provides a more complete nutrition analysis and planning experience.
