# 🎤 SECTION 12 — Interview Talking Points

## Project Discussion

For each project, I should be prepared to explain:

1. What problem does the project solve?
2. Why did I build it?
3. Which technologies were used?
4. What was my role?
5. How does the frontend communicate with the backend?
6. How is data stored?
7. What challenges did I face?
8. How did I debug the application?
9. What features did I implement?
10. What would I improve in the future?
