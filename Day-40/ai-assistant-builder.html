How this was built

System prompt design: The assistant receives a clear role, scope, objective, response structure, and rules for missing information, irrelevant requests, unsafe content, and uncertainty. This makes behavior more consistent across sessions.

UI choices: The workspace separates configuration, user input, and the final answer. Dark surfaces, warm accent colors, cards, responsive layout, focus states, loading feedback, and empty states create a polished AI-product experience.

Extend it: Add file uploads, conversation memory, tool calls, authentication, multi-step workflows, saved sessions, domain-specific templates, or analytics. For production use outside a hosted Claude artifact, route API calls through a secure backend and keep secrets server-side.

Note: This standalone demo includes the Anthropic request structure. Browser-hosted direct API access may require the appropriate authentication and platform configuration; never expose a private API key in public frontend code.
