# Day 42 – Personal Financial Command Center

## Project Overview

For Day 42 of the 60 Days Claude AI Challenge, I built a **Personal Financial Command Center** as an interactive financial management and learning dashboard.

The application is designed to help users understand their overall financial health rather than functioning as a basic expense tracker.

## Features

* Personalized financial dashboard
* Income and expense tracking
* Budget management
* Savings and financial goals
* Debt and loan overview
* Investment planning
* Subscription tracking
* Cash-flow insights
* Financial health score
* AI-style financial recommendations
* What-if financial simulations
* Interactive financial visualizations
* Progress tracking
* Financial calculators and planning tools
* Financial tips and planning checklists
* Additional AI prompts for financial learning
* Dark mode
* Responsive design
* Smooth UI animations
* Local Storage support
* Printable financial reports

## Technology Used

* HTML5
* CSS3
* Vanilla JavaScript
* Browser Local Storage
* No external libraries or frameworks

## Learning Outcome

This project helped me understand how AI can be used to design an interactive financial planning experience. I learned how to structure multiple financial modules into one dashboard and connect user inputs with calculations, visualizations, recommendations, and what-if scenarios.
