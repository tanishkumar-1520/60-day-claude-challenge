# Day 50 — Defend Your Experience

## Project
**Defend Your Experience — Adaptive Interview Defense Simulator**

## Objective
Build an interactive application that helps users defend every meaningful claim in their resume, portfolio, project, research, bio, or professional experience.

## Features
- Context selection for job interviews, promotions, freelance/client work, and portfolio/project reviews.
- Audience selection.
- Drag-and-drop document upload plus paste-text fallback.
- Claim extraction from experience text.
- Adaptive one-question-at-a-time defense interview.
- Skeptical follow-up questions focused on ownership, evidence, trade-offs, constraints, metrics, and impact.
- Evidence, specificity, and confidence scoring.
- Live progress dashboard.
- Final Defense Report with reviewed claims and improvement priorities.
- Local storage session persistence.
- Session export and Defense Report export.
- Responsive mobile-friendly UI.
- Graceful fallback when the Anthropic API is unavailable.
- Designed for the authenticated Anthropic HTML Artifact environment without asking the user for an API key.
