# Day 31 – AI Supply Chain Control Tower

## Project Overview

Built an interactive AI Supply Chain Control Tower simulation using HTML, CSS, and vanilla JavaScript.

The application simulates the role of a Head of Operations managing real-time supply chain incidents.

## Features

* Live Service Level KPI
* Customer Satisfaction KPI
* Inventory Health KPI
* Transportation Efficiency KPI
* Operating Cost tracking
* Revenue Protected tracking
* Live operational score
* 3-minute countdown simulation
* Random operational alerts
* Multiple simultaneous incidents
* Priority-based alert system
* Corrective action decisions
* Immediate and delayed consequences
* Live event log
* Pause/Resume functionality
* Sound toggle
* Help/Instructions modal
* Final performance dashboard
* Performance grading from A+ to D
* Play Again functionality
* Responsive desktop and mobile interface

## Alert Scenarios

The simulation includes:

* Port Congestion
* Supplier Delay
* Truck Breakdown
* Warehouse Running Out of Stock
* Customs Inspection
* Demand Spike
* Factory Machine Failure
* Weather Disruption
* Wrong Inventory Count
* Damaged Shipment

## Technology Used

* HTML5
* CSS3
* Vanilla JavaScript

No external libraries, frameworks, APIs, or backend services were used.

## Key Learning

This project helped me understand how operational decision-making can be represented through an interactive simulation.

I learned how to:

* Build real-time KPI dashboards
* Create dynamic alerts using JavaScript
* Implement decision-based game logic
* Manage multiple active incidents
* Apply different consequences to user actions
* Create delayed operational consequences
* Build responsive control-center interfaces
* Calculate and display final performance scores
* Design a professional operations dashboard

## Outcome

Successfully created and tested an offline AI Supply Chain Control Tower simulation where users act as the Head of Operations and make decisions to protect service levels, customer satisfaction, inventory, transportation efficiency, cost, and revenue.
