Architecture Overview

Planner defines the approach. Executor creates the working draft. Evaluator measures the draft against the rubric. Critic identifies weaknesses. Improver receives the prior evaluation and critique and creates the next draft. Memory Manager records durable lessons. Safety Monitor can stop unsafe execution. Final Reviewer receives the terminal state after a stop condition fires.

The stop check runs after each improvement pass in this order: plateau → threshold → hard safety cap. The loop is intentionally open-ended at runtime rather than using a preselected round count.
