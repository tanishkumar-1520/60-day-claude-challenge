# Day 35 — Prompt Puzzle 🧩

## Project
**Prompt Puzzle — Master AI Prompting Through Play**

## Domain
Frontend Development

## Difficulty
Advanced

## Overview

Built an interactive prompt-engineering game that helps users practice creating, improving, and evaluating AI prompts through realistic frontend-development scenarios.

The application focuses on learning how to write prompts that are clear, structured, specific, and optimized without unnecessary complexity.

## Challenge Types

### 1. Build the Prompt
Arrange prompt blocks in the correct order to construct a strong AI prompt.

### 2. Clean the Prompt
Improve a weak prompt by selecting the optimized version.

### 3. Choose the Best Prompt
Compare multiple prompt approaches and identify the one most likely to produce a high-quality AI response.

No backend, database, API, npm package, or external asset is required.

- Prompt Principle

## Prompt Engineering Lessons

### Context Matters
AI produces better results when the prompt clearly explains the situation and the intended use case.

### Specific Requirements Improve Output
Instead of asking for a generic solution, clearly define the required functionality and constraints.

### Output Format Matters
Specifying what the AI should return makes the result easier to use and evaluate.

### Constraints Prevent Unwanted Solutions
Good constraints prevent unnecessary dependencies, rewrites, or complexity.

### More Detail Is Not Always Better
An over-engineered prompt can reduce efficiency and make the actual objective harder to identify.

### Acceptance Criteria Improve Quality
Defining what "successful" means makes AI-generated solutions easier to evaluate.
