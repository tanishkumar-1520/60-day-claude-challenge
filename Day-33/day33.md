# Day 33 — Media Integrity Analyzer

## 📅 Challenge
60 Days of Claude AI Challenge — Day 33

## 🎯 Project
**Media Integrity Analyzer**

## 🧠 Objective
Build an interactive, offline-first media literacy learning application that helps users identify misleading headlines, emotional manipulation, and audience-targeting techniques in digital media.

## 🛠️ Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- No frameworks
- No backend
- No external APIs
- No external images/assets
- Fully self-contained single HTML file

## ✨ Key Features

### 1. Theme Selection
Users can choose from multiple visual themes:
- Claude Orange
- Electric Violet
- Signal Blue
- Trust Green
- Archive Gold

### 2. Headline Detective
Users analyze fictional headlines and article excerpts by choosing:
- Yes
- Maybe
- No

The application then reveals:
- Headline Accuracy Score
- Misleading or exaggerated parts
- Highlighted mismatches
- Explanation
- Fair headline rewrite
- Key takeaway

### 3. Emotion Detector
Users analyze fictional social posts, reel captions, or article excerpts.

The application reveals:
- Intended emotional response
- Target audience
- Manipulation technique
- Emotional phrases
- Neutral rewrite
- Key takeaway

### 4. Live Media Integrity Metrics
The application tracks:
- Headline Accuracy
- Source Reliability
- Emotional Manipulation
- Audience Targeting

### 5. Final Media Integrity Dashboard
At the end, users receive:
- Overall Media Integrity Score
- What they learned
- Biggest red flag
- Three practical media-literacy habits
- Replay option with randomized scenarios

## 🎨 UX & Design
The app uses a premium editorial dark interface with:
- Responsive layouts
- Interactive cards
- Smooth transitions and animations
- Progress indicators
- Hover effects
- Clear visual hierarchy
- Mobile, tablet, and desktop support

## 📚 Learning Approach
The experience follows a guided-learning model rather than a traditional quiz.

Each challenge first explains:
1. What the concept means
2. Why it matters
3. How it appears in everyday media

Users then observe a scenario, think about it, make a choice, and reveal the analysis.

## 💡 What I Learned
- How to design an educational experience using progressive disclosure.
- How misleading headlines can be analyzed by comparing claims with supporting details.
- How emotional language can influence audience reactions.
- How audience targeting can be identified from wording and context.
- How to build live metrics and a final score using vanilla JavaScript.
- How to create randomized replayable scenarios.
- How CSS variables can support multiple visual themes.
- How to make a single-file HTML application responsive and offline-ready.
- How AI-assisted development can speed up the creation of complete interactive frontend applications.

## 🚀 How to Run
1. Open `media-integrity-analyzer.html`.
2. Choose a theme.
3. Complete the Headline Detective challenge.
4. Complete the Emotion Detector challenge.
5. Review the live metrics.
6. View the final Media Integrity Dashboard.
7. Use **Replay with New Scenarios** to try randomized examples.

No server or installation is required.
