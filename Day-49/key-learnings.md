# Day 49 — Key Learnings

1. AI becomes more useful when repeated tasks are converted into reusable workflow systems.
2. Prompt quality improves when role, objective, context and constraints are explicitly separated.
3. Modular prompt blocks can produce many variations without storing hundreds of separate prompts.
4. A live prompt preview makes prompt construction easier to understand and edit.
5. Autonomous loops need explicit evaluation criteria, improvement rules, stop conditions and safety boundaries.
6. LocalStorage is useful for lightweight offline persistence in single-file web applications.
7. JSON export/import provides a simple backup and portability mechanism for local workflow data.
8. Plain-language labels and persistent explanations make an AI tool understandable to first-time users.
9. Responsive design is important when a productivity application may be opened on different screen sizes.
10. A workflow library is more maintainable when users can search, favorite, duplicate and delete reusable systems.
