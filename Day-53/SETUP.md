# Day 53 — Setup Guide

## Objective
Set up the development foundation for the Jobs & Career Assistant.

## Required Tools
- Node.js LTS
- npm
- Git
- VS Code
- GitHub account

## Setup Checklist
1. Clone the project repository.
2. Open the project folder in VS Code.
3. Install the dependencies required by the project.
4. Create the local environment file from `.env.example`.
5. Add required development credentials locally.
6. Start the development server.
7. Open the localhost URL shown by the terminal.
8. Verify the Hello World/foundation screen.
9. Run the project's build command and verify there are no errors.

## Git Strategy
- `main` = stable code
- `develop` = integration
- `feature/*` = individual features

Never commit `.env` or real API secrets.
