# Day 45 — Decision Strategist

## Challenge
Built a single-file **Decision Strategist** application as part of the **ABTalks 60-Day Claude AI Challenge**.

## Objective
Create an impartial decision framework that helps a user examine a difficult choice through:
- The real decision and trade-off
- Case for each option
- Assumptions and cognitive biases
- A 7-dimension decision matrix
- Premortem analysis
- A 7-day test plan
- A decisive verdict
- Screenshot-friendly shareable cards

## File
- `decision-strategist.html`

## Key Features
1. Dark, responsive single-column dashboard.
2. Separate card for every required report section.
3. Decision matrix with seven scoring dimensions.
4. Animated horizontal score bars.
5. Winning option highlighted visually.
6. Premortem for the top two options.
7. Seven-day decision testing plan.
8. Verdict card with hard-truth statement.
9. Three compact shareable cards.
10. Responsive mobile layout below 600px.
11. Smooth scrolling and subtle card hover effects.
12. CSS variables make the visual theme easy to modify.
