# Recommended Effort Level

## Low
Simple and quick tasks.

Complex coding, debugging, research and planning.

## Max
Only for highly complex problems that require maximum reasoning.

# Biggest Mistakes I Should Avoid

- Using the most powerful model for every task
- Using high effort for simple questions
- Providing insufficient context
- Writing unclear prompts
- Blindly trusting AI output
- Not testing generated code

---

# Final Recommendation

If I could use only ONE model and ONE effort level for most of my work:

**Sonnet + Standard**

This combination provides a strong balance between response quality, reasoning, speed and practical daily usage.

I will switch to High effort when working on difficult coding, debugging, research or complex planning tasks.

---

# Key Learning

I learned that choosing the right model and effort level for each task can improve productivity and avoid unnecessary use of higher reasoning levels.

The best strategy is not always to use the most powerful model, but to select the right model for the right task.
