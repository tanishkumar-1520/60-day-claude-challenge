# 🚀 Day 11 — ATS Resume Optimization with Claude AI

## 📅 60-Day Claude AI Mastery Challenge

Day 11 focused on using Claude AI to analyze and optimize my resume for a specific target job description.

The goal was to understand how AI can help improve ATS compatibility, identify skill gaps, and make a resume more relevant to recruiters while keeping all information factually accurate.

---

# 🎯 Day 11 Objective

The main objective was to:

- Analyze my existing resume
- Compare my resume with a target Job Description
- Generate an ATS Match Score
- Identify missing keywords
- Identify missing skills
- Find improvement opportunities
- Generate an optimized ATS-friendly resume
- Compare the original and optimized versions
- Document the complete process

---

# 🤖 AI Tool Used

**Claude AI**

### Claude Effort Level

**Low**

---

# 📄 Input Used

Two main inputs were provided to Claude:

### 1. Existing Resume

My current resume was uploaded to Claude for analysis.

### 2. Target Job Description

A relevant Job Description for my target role was provided to Claude.

The Job Description was used to identify the keywords, skills, and requirements that recruiters and ATS systems may look for.

---

# 🧠 ATS Resume Optimizer Prompt

The following prompt was used:

```text
# ATS Resume Optimizer & Resume Generator

Input:
- Existing Resume
- Target Job Description

Task:
Rewrite the resume for maximum ATS alignment and recruiter relevance while maintaining 100% factual accuracy.

Rules:
- Never invent experience, projects, employers, certifications, dates, metrics, or skills.
- Only optimize, reorganize, and rephrase existing content.
- Use relevant JD keywords naturally.
- Keep ATS-friendly formatting.

Output:
1. ATS Match Score

2. Gap Analysis

   - Missing Keywords
   - Missing Skills
   - Improvement Opportunities

3. Updated Resume

Return the complete rewritten resume as a professional resume document using the following structure:

# FULL NAME

Phone | Email | LinkedIn | GitHub

## PROFESSIONAL SUMMARY

## SKILLS

## EXPERIENCE

## PROJECTS

## EDUCATION

## CERTIFICATIONS

## ACHIEVEMENTS

The resume should be fully formatted, ready to copy into Word, Google Docs, FlowCV, Overleaf, or Canva without additional editing.
